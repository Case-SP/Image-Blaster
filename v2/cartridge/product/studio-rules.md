# Studio rules — product cartridge

This cartridge is **deterministic**. Every input object is rendered exactly three ways, in this order:

1. **product-shot** — clean studio, isolated subject, seamless backdrop, even light.
2. **in-situ** — same object in a believable real-world environment, natural daylight, lived-in but not staged.
3. **sketch** — the same object as a designer's working sketch — pen on paper, photographed flat, single ink color, paper grain visible.

There is no LLM shot-list step and no critic. The orchestrator picks one composition per shot index, in order. Inputs are short — usually just the object name, occasionally a short qualifier ("matte black office chair", "1980s tape recorder"). Treat the input as the literal subject; do not invent narrative around it.

Output is always 1:1.
