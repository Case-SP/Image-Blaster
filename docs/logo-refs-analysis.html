Takeaways for the cartridge

  • Most refs are FINISHED systems (mark + wordmark together), not sketch grids. Of 10: 2 are sketch-grid candidates (#1, #7), 5 are Stage 2 systems (#2, #5, #6, #8, #10), 1 is a brand-book spec page (#9), 2 are anti-patterns (#3, #4). The user's curation is biased toward Stage 2/3 — most useful for Phase 3+ work, not Phase 2 sketch.
  • Add a grid-with-captions variant to the sketch grid slot (Image #7). Format: "a 3x2 grid of 6 marks, each with a small grey caption below in the form Brand, descriptor, year." Emulating reference-book layout gives the model a structural anchor that yields more "real-feeling" marks.
  • Add a 1-up hero variant to the sketch grid slot (Image #6). Format: "a single hero mark centered with vast breathing room." For when the user wants ONE direction explored carefully rather than 4-6 in a grid.
  • Stage 2 (Phase 3) needs a controlled-color palette option (Image #2 Uniqlo red, Image #7 mid-century palette). Current palette slot is monochrome only. When the era register implies color (mid-century corporate), allow saturated brand color.
  • Bilingual / multi-script integration (Image #2, #8) is recurring in international brand work. Worth a slot value or post-classifier signal in Phase 3.
  • Anti-patterns confirmed (Image #3 Lamborghini chrome, #4 Versace gold). Our suffix.md negatives correctly forbid these. Worth keeping a quick "anti-pattern check" reference in the learnings doc so we know if the negatives ever leak.
  • Pictographic mountain (Image #10) and organic blob (Image #6) validate our existing mark_type registers (ICONIC PICTOGRAPHIC, FLOWING ORGANIC). Both already in slot vocab.
  • Construction-grid pairing (Image #9) validates our existing 6th grid value ("a 2x2 grid of 4 finished marks above, paired with a matching row of thin-line construction diagrams below").
